# Choosing a license

Copy exactly one of these to `LICENSE` in the new repo's root, then delete this
`licenses/` folder.

| File | Use for |
|---|---|
| `MIT.txt` | Standalone libraries, tools and templates with no ported copyleft code |
| `GPL-3.0.txt` | The engine, and anything containing code ported from GPL or LGPL projects |

See [`REPOS.md`](https://github.com/helix-bedrock/.github/blob/main/REPOS.md) for which
repo uses which, and
[`PORTING.md`](https://github.com/helix-bedrock/.github/blob/main/PORTING.md) for why.

`repo-template` itself is MIT (its `LICENSE` file).
